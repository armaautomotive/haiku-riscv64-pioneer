-----------------------------------

(1,2),fixed source windows. Shape is not actual bank-source authentication.
Fresh NODE_ID/translated identity/table/harvest/NIU configuration checks use
the existing strict Self primitive. Caller still owes independent firmware
route/source/payload/PCI/VM/clock/exclusive ownership BEFORE launch.
All32B headers are zero-written AND read back. Packed payloads arrive ONLY
via READ packets<=1088B,16 per batch,disjoint final L1 destinations. Empty
FIFO is observed BEFORE completion counters,as required by the primary NIU
counter rules. Exact read response/data-flit/accepted/sent/started deltas,
unchanged write counters,all32 outstanding slots,NIU idle and identity must
pass before another batch/operand/math. Wrapped32-bit counters supported.
No wait expiry grants retry/reset/implicit cleanup. Subsequent Run on the
same object performs zero IO,even following an invalid admission. Descriptors
also suppress further IO after the first invalid mapping.

load/compute. Its marker is NDB1,not old NFB3;fault NDBE parks without result.
All responses complete before ANY FPU instruction/configuration. Then two
complete jobs read only valid Dst32/40 and publish64 outputs. There is no
attempt to infer owner closure from that marker or from parked PC alone.
NIU command words/headers/new ROM/frame/GDDR staging all require a NEW full
native journal/STOP/HOLD/restore owner. No driver admission is loosened.
