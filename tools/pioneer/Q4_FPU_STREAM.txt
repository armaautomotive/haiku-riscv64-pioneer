Data flow
---------
One device-side RV32 program loops over all K256 blocks of a32-row matrix
band, width5120 or17408. Two disjoint L1 buffers alternate as reader/prefetch
slots. Four14-request slices fill the next slot during the first four groups
of current-slot math. Each block has56 reads/104 C64 flits:16x256B unchanged
quant payloads,32x64B exact FP32 scale/minimum metadata,8x64B BF16 inputs.
Prepared weights are6144B per32x256 band; inputs512B. Private zero64B L1
headers are initialized/read back once per job, not duplicated in GDDR.

The FPU accumulator is initialized ONCE per full-K job. It persists across
all20 or68 blocks, with exactly the original SFPU BF16-RNE, MOVD2A and four
FPU fidelity phases. Only final32 FPU outputs are scalar-read, after all math
and NoC drains. No scalar learned operand copy, host K-loop, CPU learned
product, GDDR write, runtime reference, retry or reset is introduced.

The loader requires an empty FIFO, all32 transaction credits/other queues
idle and source identity before admission. Each slice checks command echo;
GO/length/source/destination are read back. Handoff requires FIFO drain,
exact nine monotonic/wrapping counter deltas, full terminal queue/credit and
command checks, then a visibility FENCE. Only TID0 is issued, so incomplete
polls check that credit; terminal checks still cover all32. The original
65536 poll bound is unchanged. A failed or completed loader cannot issue
more IO. Previously issued autonomous replies are NOT reclaimed on failure.

Memory layout is DATA ONLY, not allocation or execution authority:
  frame74000, output98000, shared zero97000
  buffer0 raw90000/meta94000/input96000; buffer1 all+10000
  GDDR weight04000000/input04100000
The eight geometric route shapes are not firmware-bound native admission.
The cache recipe is different from both existing loader/native-BFP8 caches;
never silently alias their entries or infer full-model memory capacity.

8KiB ROM bound. -O2's11024B image was refused, not admitted by enlarging ROM.
Final text images are7824B; their hashes are pinned in the saved report.

The compiler's zero-only memset is restricted to aligned owned stack words.
Strict RV32 Machine::Step is unchanged; no byte-store decoder relaxation.

Tests cover actual compiled instruction words and one canonical L1 shared
by NoC replies, unpack, SFPU/FPU, frame, status, stack and output. The old
pipeline observer gains only default-preserving operand-readiness/address
