Current experimental code
--------------------------

A different Q4 matrix algorithm is intended to reduce repeated per-weight
conversion work. It keeps original compressed weights, creates temporary
native tiles on the card, then applies scale/minimum correction to outputs.

Locally completed:
  * Code extraction and separate FP32 output-affine arithmetic.
  * Original-byte UNPACK -> vector extraction -> integer PACK -> temporary
    native tile -> matrix dot product and genuine input sum.
  * Compiled RV32 functions tested by the existing strict software model,
    including packing/source-bank completion checks.
  * Original metadata/output correction and full-K accumulation are now
    integrated in a returning routine. Compiled software-model tests cover
    both 5,120/17,408 input widths and repeated jobs without context reset.

NOT completed:
  * Native ownership/code/memory qualification for the new returning routine.
  * Physical numerical checks and old/new matrix timing on the P100A.
  * Whole-model quality and throughput measurement of the new algorithm.

This is a new operation order, not previous BF16/GGML bit equivalence.
Synthetic tests do not establish full-model quality or hardware speed.
The unfinished component is checkpointed separately from working inference.
