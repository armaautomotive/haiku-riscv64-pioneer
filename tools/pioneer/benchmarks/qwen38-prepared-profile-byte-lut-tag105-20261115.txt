Purpose

This diagnostic pairs the exact tag99 five-section phase-profile ROOT with
the ten exact tag104 byte-index activation-LUT peers. It gives the phase
profiler the current byte-LUT worker set, so a later controlled full-model
run can reveal which measured phase dominates. It does not change the
tag104 compute peer bytes and makes no inference-speed claim.
