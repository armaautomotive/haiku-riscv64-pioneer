QGW8 final-hidden CPU head replay, 2026-11-08
==============================================

This is an isolated offline diagnostic, not Assistant Work or CPU fallback.
It accepts a hash-verified, fixed-input tag129-shaped 5120-word snapshot,
uses independently authenticated original output normalization and a
separately compiled BFP8 software output head, and ranks an observed token
against all 248320 computed logits. Both the source GGUF and the head are
authenticated by their existing code; snapshot shape/hash do not prove input
provenance. A matching top token does not prove numerical or model quality,
and disagreement does not by itself identify the underlying faulty stage.

Synthetic parser tests check the fixed identity, generation/chunks, finiteness,
hash, no-partial result and role restrictions. Replay build/argument tests and
the CPU-fixture pin/no-overwrite/symlink tests pass without real device access.

hidden snapshot to construct a private card-format fixture. That fixture is
explicitly SYNTHETIC CPU DATA, not a device observation. A real-model CPU
replay of that fixture completed successfully: the software head selected
token 70253, with logit 11.5286961 and rank 1. This matches the earlier
combined-conversion CPU head observation for the same hidden vector. It is
not a physical, model-quality, Work-mode or speed result.
