# Dense attention through resident graph simulation

The synthetic fixture feeds the actual sharded resident image four graph steps: key packing, a residual copy that replaces the shared projected workspace with distinct value data, value packing, and dense attention. The fifth all-zero record intentionally faults. The simulated fleet completed four barriers on all 120 workers; its checked mailboxes showed no completion candidate after the fault. This is not an explicit fleet shutdown.

The runs use position 2 with context 4 and position 33 with context 64. The latter reads 34 positions in two KV tiles, crossing the 32-position boundary. Both use synthetic Q/gate, K, V, RMS and rotary values, and seeded prior KV. The full KV buffers matched a separate host operator implementation byte for byte; all 9,216 output storage floats matched within maximum absolute error `1.86264515e-9`. Only the first 4,096 floats are attention outputs; the remaining storage was checked to stay zero. The host reference and device implementation share approximation primitives; this is not an independent full-precision model oracle.

The compiled worker uses 4 active cores for each key/value packing step and 16 for attention; a 120-worker barrier is not full utilization. A copy step uses all 120, but is diagnostic and does not stand for the missing value projection. The goal requires a better parallel design and real measurement. No full dense layer, model weights, physical card, valid model output, throughput, or no-reboot recovery was tested.
