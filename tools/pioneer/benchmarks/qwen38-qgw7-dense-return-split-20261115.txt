QGC1 dense-return split + QGW7/QDM2 matrix-attention handoff
===========================================================
2026-11-15. Offline build and instruction-simulator qualification only.
No device, native driver, Work mode, full model, quality result or TPS claim.

Change
------
The inspected persistent ROOT text had overflowed the fixed STOP page by
10,016 bytes when dense-return routines were linked. The earlier
`--dense-return-split` option moved five emitted routines into the existing
64 KiB BF16 code window. This checkpoint removes the artificial ban on
combining that placement with the explicit `--hybrid-matrix-attention`
inspection role. It changes placement and selector accounting only; it does
not change arithmetic or authorize installation.

The new regression builds the matrix-attention ROOT with the split enabled,
checks that the moved routines land at 0x20000..0x30000 and that code remains
within the fixed text/STOP boundary, then simulates the linked ROOT. It also
builds a separate QGW5-identity control ROOT with the same safe placement,
the default QGW7 worker, an isolated BFP4 leaf, and the explicit three-product
PV QGW7 inspection variant. The test executes actual linked ROOT dense-job
instructions into actual emitted QGW7/QDM2 worker instructions, runs the
three attention phases, checks the expected output, rejects the legacy job
identity at the QGW7 worker, and continues to the next BFP4 projection.
