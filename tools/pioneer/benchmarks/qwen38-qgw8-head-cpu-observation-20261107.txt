QGW8 combined FFN/head comparison: CPU-ONLY, ONE FIXED TOKEN
===========================================================

An isolated one-token test compares original model logits with the QGW8
11-layer-BFP8 FFN alternative and a BFP8 output head, all on the host CPU.
The original fixed-token trace must match the independently pinned trace.
The candidate uses the actual final hidden state, the original output RMS
weights, and software BFP8 conversion/matrix arithmetic to calculate all
248320 output logits. This comparison includes arithmetic differences, not
only quantization error. It is not card execution, a throughput benchmark,
Work-mode integration, natural chat or an answer-quality qualification.

The three comparisons use the entire 248320-token distribution. KL is
original-to-candidate in nats. The middle comparison uses the same converted
FFN hidden state with each head, isolating head format AND arithmetic changes:

 comparison                original top  candidate top  KL          top-5 overlap
 FFN conversion only       70253         70253          0.321765477  4/5
 head, same hidden         70253         70253          0.000365890  4/5

The head-only error was much smaller than the combined error on this single
input, while the combined KL and 3/5 top-five overlap are substantial enough
to require further investigation and broader evaluation. A matching greedy
token is not a quality pass. The unconverted reference head and converted
head use different software arithmetic as well as different weight formats.
No P100A instructions, performance, generated answer or Work path were tested.
