Implementation
--------------
ONE new persistent ROOT runs original hidden input -> learned RMS ->
Q/G,K,V -> four-group learned Q/K normalization and RoPE -> retained dense
attention -> O -> original-input residual and learned post-attention RMS
-> Q4 gate/up -> SiLU(gate)*up -> Q4 down -> final residual. The SAME119
mixed QMW1 workers stay alive across every stage and successive frames.
There are no host-produced intermediate values, worker boots, tensor resets
or STOP transitions between operators. CPU dot-reference validation is not
selected by the matrix Work jobs. Independent external observers are used
only for qualification, never as a source of controller products.

The first residual uses the ORIGINAL pre-normalization5120-element hidden
vector, not the normalized vector consumed by Q/G,K,V. Both are preserved
separately. The O projection consumes the actual6144 gated attention
values; gate/up consume the actual post-residual normalized5120 values;
down consumes the actual17408 SiLU products. The final5120 values add the
actual down projection to the saved post-attention residual, each with one
rounded F32 addition. SiLU uses the existing wide-domain stable sigmoid,
not a clipped or CPU-substituted result.

FFN matrix recipes are immutable DATA: canonical Q4 geometry for all119
workers, K5120/N17408 for gate/up and K17408/N5120 for down. All caller
sequence placeholders are ZERO. The controller obtains actual live worker
nonces and binds next operations privately. No recipe, layout, image flag,
receipt or arithmetic test grants native/original-source/Work ownership.

Transfers use source/boot/outer/current-frame seals, full10-word command
readback, exact cumulative counter deltas, bounded waits and inert fault
terminals. Recurrent/KV/token state is NOT committed by this program.
Intermediate GDDR output, including a partially written final hidden
vector, remains PROVISIONAL until the complete block summary and finished
sequence publish after final seals. Even that publication is only a block
result, not a canonical whole-model token/state commit.
