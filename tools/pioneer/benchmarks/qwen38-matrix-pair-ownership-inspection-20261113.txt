Two-core learned-band ownership inspection, 2026-11-13

The single-core real-QKV band diagnostic cannot run concurrently: its lease
requires all cores held even during its cleanup. This separate initially offline
prototype snapshots two disjoint core images, stages both before releasing
either, rechecks the held fleet, starts both, and observes both before holding
either. It restores both L1 images and the original shared host TLBs only
after both terminal proofs and a fresh all-cores-held check. Once an I/O or
proof fails, it retains ownership and attempts no retry or cleanup.

The ASan/UBSan mock test requires both starts before publishing either fake
completion. It injects precomputed output words to check routing (not matrix
arithmetic), verifies both complete L1 snapshots and TLB restoration, and
checks ten timeout, status, reset, write, mapping and source-failure cases.
Explicit inspection-role tests reject kernel, driver, Work and validation builds.
The learned QKV export identity is checked without publishing its bytes.

Follow-up: the same two-core owner has also run the pinned real-QKV band
instruction image twice in the host RV32/matrix instruction simulator, with
two distinct learned-weight samples and separate L1 images. The simulated
device waits until both are released before serial host execution; all 128
returned words match the existing expected results, and both L1 images and
shared TLBs are restored. ASan/UBSan passed. This does not emulate hardware
timing, overlapping device execution, PCIe windows or reset races.

Cross-route alias hardening: per-core verification alone would not detect a
second staged image overwriting an aliased first core. The owner now rejects
identical sample selections and rereads both complete images after staging
both, before any reset/release. A fake-MMIO test forces the two routes to the
same L1 and confirms refusal, no processor release and retained quarantine for
all three distinct pairs of pinned QKV samples. It does not prove real
hardware routing or detect every conceivable partial alias of equal bytes.
