selections, altered shape/type/byte metadata refusals, and three selected
5120/6144-wide tensors at three offsets against the frozen BFP8 converter.
The existing separate converter tests cover synthetic Q8 values independently
of this selector. Native/Work/reference/fast-math and mixed-preparer roles
were rejected. A host build rejected invalid arguments and a nonexistent
original without creating a cache. Two independent Haiku RISC-V candidate

The initial builds differed only in a temporary path embedded in DWARF5 line
