====================================================

Purpose
-------
Record the current reproducible build boundary for the older complete
full-offload ROOT builder. This is an offline build audit, not a model speed
result or a claim that Qwen runs on the P100A.

Build command
------------
  env -u CPATH python3 tools/pioneer/build_qwen38_full_offload_root.py \
    /Volumes/HaikuBuildLocal/generated.riscv64 \
    /private/tmp/q38-root-audit-final-20261115 --inspect-candidate

The builder now exposes the SDK's staged public headers to nested compiler
calls when the cross-toolchain sysroot include directory is empty. It compiles
the required returning components directly instead of first trying to link an
intermediate non-full-offload ROOT image. That lets the requested full-offload
ROOT compile reach its own linker and report its actual size constraint.
