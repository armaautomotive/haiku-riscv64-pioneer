Separate exact source format
----------------------------
PioneerQ38NativeQ4WeightCache snapshots the complete original tiled plan.
Every original851-tensor/state/workspace extent stays where it was,with
full8192 context and TWO recurrent-state slots. Only Q4 primary data uses
the lossless native permutation;other formats and ALL256 original metadata
bytes per Q4 tile remain untouched. Integer q=z+7+escape,where
z=min(q,14)-7 and escape=(q==15). No weight requantization,learned float
products,CPU inference/reference outputs or fallback is prepared/uploaded.

Each Q4 fragment has two keyed,private,verified cache entries:
 * Fixed64B-header manifest plus aligned4B-per-tile correction indices.
 * ONE atomic bundle:original-size native primary plus correction sidecar.
Index high2bits are dense0,sparse1,empty2;low30bits are sidecar-relative
16-aligned offsets. Empty masks have offset0/no payload. Sparse payloads
contain32B row-presence bits followed by nonzero16bit row masks;dense
fallback is512B. Original metadata is byte-exact. Layout padding is zero.
Manifest geometry/reserved fields/order/overlap/tails are checked before
bundle preparation. Missing/corrupt upload entries fail without repair.
The ordinary cache still owns atomic publication,SHA and filesystem checks.

No device addresses are stored in cache payloads. Correction proposals are
assigned deterministically AFTER all original allocations in EACH SAME
bank,rounded4KiB,within the EXISTING seven3GiB caps. A proposal is NOT a
native allocation/mapping/NoC capability. No legacy loader or device ABI
selects these bytes. Separate ReadPage(primary/correction) interfaces avoid
silently feeding native bytes to the original raw-weight loader.

PioneerQ38NativeQ4CachedPages is a read-only upload adapter. One verified
64KiB snapshot serves consecutive4KiB pages without hashing that same
chunk16 times. Every buffered read rechecks original readiness,exact
prepared key and the cache file identity. A source change or corruption
outside the currently requested chunk also revokes the snapshot. Payload
reads have NO conversion,payload creation,repair or device submission path.
Initial binding uses the existing private marked-cache directory API.
