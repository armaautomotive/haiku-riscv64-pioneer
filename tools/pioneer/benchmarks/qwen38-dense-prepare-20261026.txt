Implemented
-----------
NEW separate QDP1 local component for the downloaded model's qwen35
geometry:24 query heads,four KV heads,width256,partial rotary width64.
Each invocation handles six interleaved [Q256,gate256] heads and one K/V
head. It performs learned per-head RMS256,rotates only dimensions0..63,
preserves192 unrotated dimensions,keeps gate bits separate and unchanged,
and packs the new K and V as IEEE binary16 RNE. There is no accidental
first6144-query/last6144-gate split,no extra1 added to converted GGUF norm
weights,and no use of the old small-model128-wide attention geometry.

RMS uses the existing software-binary64 positive reduction with a NEW
exact power-of-two Mean256. Sqrt/division and fused rotation use existing
qualified integer implementations,not unsupported BRISC instructions or
host learned arithmetic. The explicit bounded normal-domain checks refuse
unqualified inputs instead of silently flushing or accepting nonfinite
results. Partial output on arithmetic failure is LOCAL scratch only.

The component currently consumes a64-float cos/sin table in local memory.
The intended resident text path owes a fixed8192-position table uploaded
ONCE at model initialization(2MiB),then device-only position-bound reads.
That table owner/upload/position binding is NOT implemented here. Offline
tests provide raw table DATA,not per-token runtime CPU preparation. Text
positions have identical temporal/spatial indices; multimodal positions
require separate qualification and are not claimed by this component.
