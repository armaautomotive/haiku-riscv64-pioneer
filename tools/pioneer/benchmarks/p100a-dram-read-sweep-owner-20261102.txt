PioneerDramReadSweepOwner.h implements a separate single-attempt algorithm:
 1. Validate coherent7-bank/root-NoC proof DATA, bounded parameters, pristine
    result and the exact private allocation/scope contract before any IO.
 2. Enter the clock lease; capture and independently re-read all6 original
    mapping words. Check every120 worker reset mask physically in the IO
    model, then select fixed logical worker(1,2) and a pristine initiator.
 3. Save and independently re-read ALL6490 original L1 words while held.
    Install only the frozen code, new frame and cleared report, boot last.
    Independently verify EVERY cleared report word before processor release.
 4. Initialize/reset while known held, launch once, wait finitely. Accept
    ONLY current immutable code/frame, bound report/counter/idle checks
    and the authenticated pair of self-jumps. PC/report alone is not proof.
 5. HOLD once only after those checks. Recheck all120 workers held. Copy the
    last full raw chunk, then independently read the SAME GDDR payload via
    the selected read-only mapping. This checks only that last chunk, not
    every byte of the8MiB, full capacity, authenticity or all-card bandwidth.
 6. Restore every saved L1 word with boot last; re-read the ENTIRE final
    snapshot again. Restore original NIU/config and mapping words, leave
    the clock lease, then check the original mappings again.
Any uncertainty latches the private owner and calls memory-only retention.
There is NO further IO, second reset/start, cleanup, retry or unreserve.
The inner closed flag is NOT a whole native-driver END/disposal authority.
