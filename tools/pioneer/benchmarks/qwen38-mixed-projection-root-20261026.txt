Implementation
--------------
New QMP1 ROOT code keeps the SAME119 QMW1 workers alive across the dense
Q/G, K, V and O projections. It reads their ACTUAL current closed-job
nonces, immutable jobs/boots, physical sources/reset/PC and last receipts.
All119 are admitted before the first worker write, including inactive
workers for the smaller K/V projections. A fresh boot/ready marker or
caller-supplied next sequence is not accepted as upstream execution proof.

Canonical DATA recipes have ZERO sequence placeholders. QMP1 validates
the complete original shape, banks, weight ranges and exact one-to-one
output-row coverage, snapshots them and assigns the next worker nonces
from live observations. The ROOT's private boot/frame/doorbell seal uses
reserved s11; its own private sequence/counter history survives each job.

Actual ROOT instructions quantize F32 inputs in256-element chunks into
native operands and compact scales. Q/G/K/V use K5120 and Q8_0-compatible
input packing; O uses K6144 and signed Q8_K input packing for Q6_K weights.
The quantizer runs on the card's scalar processor, NOT on the host CPU.
Jobs select Work math with no CPU dot-reference validation. Q/G produces
12288 F32 values, K and V1024 each, and O5120. Q/G/O use119 workers;
K/V use64, without stopping or reinitializing the other55 workers.

The ROOT launches ALL matrix jobs before gathering results. Each actual
receipt must match the live nonce, worker, all16 original source words,
all eight before/after counters, exact arithmetic count, final NoC command
and all reserved fields. Actual current physical counters and source/boot/
closed-job/status/PC are checked again. Gathered output rows must be finite.
The raw input, native operands, compact scales and recipes are rechecked.
Only then are output bytes scattered to the recipe's GDDR workspace.

GDDR writes are PROVISIONAL data, NOT a state/KV/token commit or a consumer
producer grant. A successful summary/finished sequence is published only
after all transfers, source/frame/input seals and counter checks pass.
An unknown transfer parks the controller; it cannot retry, reset workers,
continue IO or publish current success. No CPU expected product is used
by the controller or its simulated byte-transfer fabric.

Execution qualification
-----------------------
The fixture starts119 actual QMW1 programs ONCE and first runs real Q8/Q4/
Q6 matrix operations with different nonzero histories, plus real paired
GDN operations on heads0/31/47. Projection roles then share those SAME
RV32 registers, tensor/config/thread/LReg/Dst arrays, sources and counters.
ClearTensorState() is an ASSERTION of drained state, NOT a tensor reset.
Only raw synthetic learned/input endpoints and observer geometry change.
Poisoning affects L1/scratch operands, never an expected tensor product.

Every native operand/scale is compared with a separate input-quantization
observer, and every gathered/scattered matrix row with exact FP32 and an
independent FP64 observer. Expected products do not enter the fabric.
Two different raw inputs exercise Q/G -> K -> V -> O twice. The fault suite
also resumes one valid K projection after its OS-fork fault snapshots.

Fault branches use OS-fork snapshots of an ALREADY EXECUTED VM world,
including snapshots at actually reached pending NoC-submit instructions.
No branch changes the emulated PC, registers or private sequence to invent
readiness. This avoids repeating identical admission/math merely to flip
each of64 receipt words. All64 are individually tested. Other cases cover
timeouts, root source/header/boot/recipe corruption, all10 command words,
active/idle peer reset/STOP/source/status/boot/job mismatch, malformed
recipes, caller nonce placeholders, invalid raw input, changes to each
independent idle counter, and late raw/native/scale mutation.
Additional final-scatter faults check timeout/counters, all10 post-transfer
command words and source/header/boot mutation. A partial provisional write
does not become a published producer or authorize another transfer.
