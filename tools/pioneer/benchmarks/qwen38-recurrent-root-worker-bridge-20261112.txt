Linked recurrent ROOT job to matrix worker, offline simulation

The actual RV32 recurrent ROOT scheduler and job builder emitted a role-13,
6144-input job using a canonical layer-0 output-projection workspace record
and a boot record from the separately built worker simulator. The job's 256
bytes were passed unchanged to the worker endpoint. Actual simulated
producer instructions packed 24 input chunks; the compiled worker and BFP8
leaf then processed a real blk.0.ssm_out.weight sample, matching all 32
independently prepared golden values for each assigned output band. A bad
boot record and a job with the wrong role were rejected.

The host pipes represent transport, not a simulated ROOT NoC transaction.
ROOT record loading was stubbed with canonical bytes, worker endpoints and
matrix fabric were simulated, and the same 32-row sample was reused across
the assigned bands. Only one worker and one projection were connected. The
runner pins all executable images and real-sample headers, checks extracted
ELF sections and symbol tables, and runs with ASan/UBSan. No learned model
data was added to the repository.

This connects two previously separately tested emitted-instruction paths; it
does not execute ROOT's complete prepare/dispatch/gather/scatter lifecycle,
the other 118 workers as a retained cohort, the complete recurrent layer,
native ownership, hardware, full-model quality or speed. The 20 tok/s goal
remains unmet.

Follow-up: the bridge now transfers 119 actual linked ROOT jobs to 119
separately simulated worker histories. All 5,120 output rows were covered
exactly once and matched their assigned golden results. The three independently
checked real 32-row samples were interleaved across workers and local bands;
they are repeated, not 5,120 distinct learned rows. The 24 producer chunks
were executed once to prepare the shared synthetic input; worker 1 also ran
its own producer before its matrix job. Bad boot and wrong-role job tests
still failed as intended. This remains host-piped, sequential worker
simulation: it does not establish concurrent NoC transport, retained cohort
history, ROOT gather/scatter, native ownership, card execution or speed.

Second follow-up: the same emitted-job bridge passed all 119 workers for the
three layer-0 recurrent roles: gate/tensor 3 (6,144 output rows), QKV/tensor
5 (10,240) and output/tensor 16 (5,120). All rows were covered exactly once
and matched their assigned, repeated independently checked sample. Bad boot
and wrong-role jobs were rejected in each run. Source-specific model bytes,
ROOT/worker ELFs and extracted sections were pinned. The same simulation and
single-layer limitations above continue to apply; this is not full-model
arithmetic or a hardware timing result.
