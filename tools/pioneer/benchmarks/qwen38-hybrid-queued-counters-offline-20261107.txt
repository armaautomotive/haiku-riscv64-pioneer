Qwen3.8 27B / QGW7 hybrid queued-counter experiment, 2026-11-07

Status: OFFLINE INSPECTION ONLY. This is not a driver, installed image, Work
target, physical hardware run, real-model generation, or throughput result.
Do not use this image on the P100A until separately qualified. The last valid
full-model physical measurement remains 0.17287 token/s on an older path; it
does not measure this experiment and is not an all-matrix implementation.

Motivation: the earlier physical decode profile spent about 13.49% in its
gather/wait category, and QGW7's BF producer/matrix completion paths submit
eight independent 4-byte peer-counter reads serially. This inspection-only
variant queues those same eight reads and waits for complete, sealed results.
It does not remove any packets or prove any speedup. Results from the older
profile cannot be used as a prediction of this different candidate.

Safety: the role requires the exact returning recurrent QGW7 inspection profile
and refuses native, kernel, Work, CPU-reference, fast-math, old counter-gather,
and conflicting TID profiles. It requires FIFO mode already enabled, checks
the initiators, 16 command slots and 32 TIDs for quiet, seals packet sources,
checks all 10 words for each command, verifies receipt and peer-counter
deltas, and publishes no gathered output/counter rebase on failure. FIFO mode
is never modified. There are still eight reads; the test is queue overlap,
not a larger atomic transfer. The default QGW7 path is unchanged and the old
generator rejects the queued image instead of accepting it as tag127.
