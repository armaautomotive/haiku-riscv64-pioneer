Implemented

not104's QCS1. It wraps each of the two complete32-output full-K jobs in
bounded read-only mcycleh/mcycle/mcycleh sampling. Interval includes the
on-card loader/setup/prefetch/NoC/math/drains,not host authentication,
staging,output readback or cleanup. Same numerical compute templates,
packets,barriers,counters,poll limits,producer slots and operands.
This is not an isolated FPU-only measurement or all119-worker benchmark.

its vector from ROOT L1,so future timings must retain that distinction.

Two eight-word records occupy0x98100..0x98140,already inside the complete
old L1 journal. They do NOT fit104's immutable-zero policy:old104 must
NEVER run these images. A separate native identity/interface is still
required to capture/verify/restore the records safely. No owner,staging
script,installed driver or Work selector accepts this new BUILD here.
Clock failure/backward/zero yields explicit unavailable DATA. It neither
changes math nor supplies a completion/cleanup grant. No cycles/seconds
or tokens/sec conversion is made from a synthetic clock.
