PURPOSE
The previous worker binds each recurrent layer's 96 logical head-half tasks
to peers 1..96. Recurrent state then needs 48 x 32 KiB slots per peer, but
the measured untouched QTP3 L1 region has only 31 contiguous safe slots (34
with 4 KiB scatter). This candidate maps the same 96 logical tasks/layer over
119 peers using the existing task-placement helper. All 4,608 assignments
are one-to-one within each layer, and the state load is balanced at 38/39
slots per physical peer. This is descriptor/task-route work only: it does NOT
implement the dispatcher, state cache/page loader, or native owner.

EMITTED CANDIDATE
The separately built QRJ1 candidate validates the mapped peer for both the
raw-input and recurrent-state descriptors, verifies that the pair agrees,
then uses the existing one-worker Q/K/gate and GDN recurrence instructions.
The GDN state packets already use the authenticated descriptor peer as the
destination. The default Work/legacy build role remains unchanged; the
redistributed role has a separate builder and explicit compile define.
