Qwen 27B hybrid worker dispatcher: OFFBOARD ONLY, November 7 2026
=================================================================

Result: experimental linked RV32 worker runs BFP4 and BFP8 calculations
through its dispatcher in simulated NoC/FPU. Neither has run in the live
model or on the P100A in this worker image. No model speed claim.

Command:
  python3 tools/pioneer/tests/run_pioneer_q38_hybrid_worker_tests.py /Volumes/HaikuBuildLocal/generated.riscv64

Rebuilds separate experimental worker images and leaves; address/undefined
sanitizer tests execute actual worker instructions. For each format, K5120
on peers 1 and 119 and K17408 on peer 119 yielded 64 expected synthetic
words per job, with simulated transfers/counters. Malformed format faults
before transfer. The BFP8 image changes the mask to test layer zero: it is a
test-only image, not the proposed layers 48..60 configuration. 22848
relocated job records pass the new frame-shape checks.

Important finding: the prior proposed GDN code location at 0xb8000 overlaps
the BFP8 staging area even at K5120 and BFP4 staging at K17408. Simulation
detected this when staged header verification read code instead of zero.
The experimental linked image relocates GDN code to 0x170000; simulation
refuses writes through code windows. Linker limits this code to 0x17ffc0.
This establishes only the tested simulation layout, not full memory or peer
ownership, safe native snapshots, immutable source/input lifetime or hardware
execution. No experimental image is authorized for installation.

Existing full-model physical measurement remains 0.17290 tokens/sec.

Follow-up: the worker receipt predicate is exercised against all six
simulated dispatcher results, with 2056 independent proof/counter mutations
per result rejected, and cross-compiles for RV32IMF without runtime helpers.
The final NoC command reads the input, not the weights: altering a valid
weight address in the job can leave the receipt valid. ROOT must compare
the actual closed job against independently authenticated placement; a receipt
is not that comparison. No ROOT or production path calls this predicate yet.

The read-only old-journal audit finds, per peer, 118768 words of maximum
BFP8 weight staging, all 17408 input-staging words and 9216 words of the
relocated GDN reservation outside the old QGW4 saved ranges. All 119 peer
snapshots have identical geometry. The stage shares the dense-attention
scratch region, so a real owner also needs proven phase/lifetime separation.
These observations do not implement save/restore or establish other ranges
are safe; they expressly prohibit reusing the old snapshot for this image.

Converted-address translation follow-up: from the existing original paired
recipe and a proposed seven-bank stripe table, a freestanding helper derives
converted job addresses and checks geometry before publishing any result.
Host tests compare all 22848 jobs against the independent canonical planner,
including both widths, all 64 layers and table/recipe fault controls. The
separately compiled actual RV32 helper executes 1190 assignments in the
simulator across both formats, both widths and BFP8 boundary layers; invalid
table input returns without output writes. The actual model ROOT does not yet
call it. An aligned but incorrect destination can pass geometry, so actual
ownership, table authentication and initialized-page proof are still needed.
