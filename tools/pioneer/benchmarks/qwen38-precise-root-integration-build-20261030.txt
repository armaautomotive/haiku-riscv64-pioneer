Implemented device path (not merely a proposed math helper)
---------------------------------------------------------
The exact returning FP32/local-source profile dispatches operation3 to the
first68 workers before each 17408-input/type12 down projection. Each worker
reads its actual256 gate/up values from shared card memory, executes the
previously qualified precise activation+packing capsule and writes actual
512B native operands plus a fresh128B scale/identity line.

ROOT admits ALL119 workers before its first descriptor write. It stages
68 descriptors/jobs, releases real next nonces, then checks actual returning
WAIT, closed boot/job words, inner capsule words, descriptor, proof, current
physical source registers and before/after physical NoC counters. The proof
is bound to the same external job/nonce, layer, position, input token and
four owner identities. There is no caller-supplied ready/completion flag.

Only after those checks does ROOT compact68 scales into the existing
zero-padded320B scale buffer and read the actual34816 native bytes in three
bounded packets. The existing down-matrix consumer reads those packed bytes.
The new route does not read activated F32 back to ROOT or requantize it there.
Other projections retain their current quantizer. Existing default QGW1
families remain separately selected; QGW2 is not a live old-cohort update.

The HOST original-flow adapter transports the four encoded worker packets
through the same shared byte fabric. Its numerical observer reads actual
worker activation values before any down job is released and checks the
actual ROOT native words/scales against an independent packing control.
It does not supply numeric products, PC/register state or private phase.
The no-CPU-reference Work implementation is not replaced by this HOST test.
