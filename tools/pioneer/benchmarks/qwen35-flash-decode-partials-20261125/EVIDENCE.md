# FlashDecode-style temporal partials, offline

This compile-only witness assigns the 120 potential workers to four KV heads, 30 per head, and gives each a disjoint contiguous position range. Each worker's assigned KV positions can serve four query heads; short histories give some workers empty ranges. A merge combines unnormalized online-softmax maxima, denominators and value sums with maximum rescaling. This follows the work partition and reduction described in [Tenstorrent's FlashDecode report](https://github.com/tenstorrent/tt-metal/blob/main/tech_reports/FlashAttention/FlashDecode.md); that report targets Wormhole and does not establish P100A performance.

`sh tools/pioneer/tests/run_pioneer_qwen35_flash_decode_partial_tests.sh` passed with ASan/UBSan. It checks complete disjoint partitions through maximum position, short-history empty ranges, forward and reverse merge, invalid arguments and non-finite data. Synthetic attention positions 0–127 matched the existing sequential online implementation within `2.68220901e-7` absolute and an independently computed double-precision softmax at positions 0, 33 and 127 within `4.43834964e-7`. The simulated loop reads one K/V entry per KV head and position for the four query heads, but this is not a device traffic measurement. The target witness cross-compiled for RV32IMF; individual merge/assignment frames are 48/16 bytes, not a whole-program stack bound. Missing compile flags and qualification builds are rejected.

No resident device worker, tile transport, inter-core communication, stable visibility, reducer synchronization, matrix-engine SDPA, graph integration or hardware safety proof exists for this design. It cannot currently replace the sharded output path. No card was accessed and no model output or throughput was measured.
