Pioneer Qwen3.8-27B Q4_K_M — prepared-input exact activation LUT experiment
Date: 2026-11-15

Purpose

PreparedQ4Inputs maps authenticated signed integer activations into exact
BF16 bit patterns before the exact Q4 matrix worker consumes them. The old
path normalizes each value with integer leading-bit logic. This experiment
uses a 129-entry signed-magnitude lookup table for that exact mapping. It
does not approximate weights or arithmetic and does not change the default
worker path. The candidate is experimental and remains separate from the
default tag102 build. It now has an offline-only, distinct tag103 native/client
role; it is not installed, hardware-qualified, or exposed in Assistant.

Counts are simulated RV32 instructions for two changed jobs, not card cycles,
latency, or tokens/sec. For K5120/groups1, PreparedQ4Inputs itself fell from
365,604 to 213,298 retired instructions in the same synthetic profile. This
indicates a useful offboard optimization in activation preparation, but does
not predict end-to-end model speed; matrix execution, memory/NoC stalls,
attention/state, and device transport remain unmeasured here.

Pioneer reachability and safety

The controlled restart restored ICMP reachability at 10.0.0.247, but strict
SSH rejected the host's changed ED25519 fingerprint
SHA256:rO4GFm7hqDNLDIEDMVFgMgWfFkYsMd4BGhdpr6DLnS8. No host-key bypass,
device login, native build install, hardware test, model run, or physical TPS
measurement was performed. Verify that fingerprint out-of-band before any
SSH-based install or benchmark.
