Change
------
After all previous worker receipts are admitted and PushedBegin completes,
retain each exact 64-word job when it is constructed for dispatch. Gather
uses that job instead of reconstructing and copying it a second time. The
new live-field check binds the retained job to the CURRENT descriptor,
partition and nonce before the unchanged receipt grammar is consumed.
Job/doorbell commands, worker math, receipt/counter checks and source
guards stay in place. The selector is build-only, not a Work mode or a
native/physical qualification; the original path stays available.

Open gates and decision
-----------------------
No physical device has run this image. It remains EXPERIMENTAL, not accepted
as faster or ready for Assistant. Still required: compare the actual old/new
returning RV32 paths and their fault behavior, construct a separately pinned
native diagnostic with safe ownership/END, then run a fresh bounded identical-
input hardware comparison and restore/verify the stable driver. Reject if
not faster or if safe fault behavior cannot be established. The live check
costs instructions and may erase the expected gain; even a successful change
addresses only an unmeasured subset of the 13.49% gather/wait profile bucket.
