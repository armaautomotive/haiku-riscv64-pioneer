Pioneer Qwen 3.8 GDN scattered-L1 state experiment — 2026-11-14

Status: offline candidate only. Nothing was installed, selected, or run on the
Pioneer. The board's current SSH host-key mismatch remains unresolved, so no
physical validation was attempted.

Candidate
---------
The combined emitted RV32 GDN worker has an explicitly gated
PIONEER_Q38_GDN_SCATTERED_STATE_EXPERIMENT build with cold-fill and warm-hit
modes. A cold miss performs the two 16 KiB NoC reads for the current 32 KiB
GDDR state, fills eight scattered 4 KiB L1 pages, and computes. A warm hit
uses those existing pages and skips the two current-state reads. Both modes
still write the 32 KiB next-state slot transactionally to GDDR. The root
validates page addresses and cache mode before any input-stage NoC operation.
The default build path is unchanged. The role header rejects Work,
CPU-reference, native, kernel, and root-qualification roles.

The offline emitted-worker simulator passed 160 positive cases across all 96
halves, seven banks, both slots, and four 16-step non-resetting chains, with
exact comparison of all 8,256 state/output words. The chains exercise the
11-packet cold path and 9-packet warm path. It passed 4,175 injected fault
cases, including invalid page-table entries and cache mode, plus
command/descriptor/counter/state faults. Malformed metadata stops before the
first combined worker NoC/SFPU action. AddressSanitizer and
UndefinedBehaviorSanitizer were enabled. A role-guard syntax test passed.

This is not a hardware benchmark: the NoC/GDDR endpoint and accelerator fabric
are simulated; the test does not execute a full Qwen token, measure latency,
validate long-context model quality, or prove initialized L1 residency.
Tokens/sec improvement is therefore unknown; no speedup is claimed.

Related cache-capacity evidence
------------------------------
The existing inspection-only 119-peer redistribution/capacity test also
passes. It maps the 4,608 recurrent half-states (144 MiB total) over 119
physical workers and finds 4,046 states (about 126.4 MiB) fit in currently
identified safe fragmented L1 pages; 562 states (about 17.6 MiB) spill.
This is a useful target for an address-indirect loader, but the existing GDN
runtime rejects this redistribution and the inspection does not establish
that these pages can remain reserved alongside every model phase.

Still required before hardware use
-----------------------------------
* A native allocator that reserves and pins all eight L1 pages for the correct
  layer/head/slot and proves address bounds, ownership, and cache lifetime.
* Token/slot epoch integration so current-state pages become authoritative
  only after the whole model token commits, with rollback on any worker fault.
* A complete native Qwen path and measured full-token benchmark. This worker
  still does not establish all-matrix-engine execution or full P100A offload.
* Re-resolve and verify the Pioneer SSH host key before remote diagnostics or
  any physical test; retain the default image as the known-good selection.
