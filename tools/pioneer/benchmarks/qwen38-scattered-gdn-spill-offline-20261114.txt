Pioneer Qwen 3.8 GDN scattered-L1 GDDR-spill candidate — 2026-11-14

Status: offline emitted-image evidence only. The candidate was not installed,
selected, or run on the Pioneer. The current SSH host-key mismatch is
unresolved, so no physical validation was attempted.

The scattered-state worker now models three cases:

* Cold fill (mode 0): read current GDDR state, copy it into eight scattered
  L1 pages, compute, then publish the next state to a different GDDR slot.
* Warm resident hit (mode 1): skip the two GDDR current-state reads, compute
  from the pages, and publish next state to GDDR.
* Capacity spill (mode 2): read the current GDDR state into the contiguous
  local prior buffer, compute without using cache pages, and publish next
  state directly to the distinct GDDR next slot.

The root validates the mode before input NoC; modes 0/1 additionally validate
the page table. Summary validation distinguishes warm (zero state reads) from
cold and spill (two state reads). The default, unselected image path is
unchanged.
