Outcome and scope
-----------------
The persistent peer now has a separate, compile-time-exact op6 that reads
one 256-F32 gated-output chunk from its fixed GDDR workspace, performs the
existing Q8_0 quantization on the card's RV32 softcore, and writes 512 native
operand bytes plus a fresh 128-byte scale/ancestry line. It returns to the
same persistent matrix/Conv/GDN loop without reset or a host callback.

All 24 chunks cover the 6144 gated-output lanes. The new QOL1 grammar binds
all 48 recurrent layers, positions 0..8191, producer phase, token ID, bank,
workspace, worker route, source seal and eight identity words. The older
QOI1 grammar is deliberately unchanged and NOT accepted as QOL1. In
particular, the old layer0/position0-only descriptor was not silently
broadened. These fields are DATA checks, not proof of an initialized model,
current producer, native ownership or token/state-slot commit.

Every packet verifies the same job, boot record, source, descriptor, four
empty queues and 32 empty tags. Actual counters must match the preceding
receipt BEFORE the next command; foreign movement is never accepted as a
new baseline. Ten command words are checked before submission, after
completion, before replacement by the next packet, and while forming the
final proof. Counter aliases, unsigned wrap, and all eight counter deltas
are checked. Raw input is poisoned and read back before the actual read;
the quantizer publishes no partial result on invalid input. UNKNOWN parks
without another packet, reset, restoration or retry. The 65536-poll limit
is an iteration bound, not a measured physical watchdog deadline.

This is a necessary persistent-worker component, NOT complete on-card
27B inference. The current installed driver was NOT changed. No model
tokens or silicon timings were measured here. Last genuine whole-model
rate remains 0.207893161 tokens/sec; 20 tokens/sec is still UNMET.
